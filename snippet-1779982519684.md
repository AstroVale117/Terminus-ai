# terminus red-team simulation framework

this is a polyglot advanced persistent threat (apt) simulation lab. it integrates rust, go, c, python, and powershell to demonstrate modern lateral movement, edr evasion, and decentralized command & control.

**disclaimer: for authorized defensive research and educational use only. do not deploy outside of the provided docker lab environment.**

## prerequisites
- docker & docker-compose
- golang 1.20+
- rust / cargo
- gcc / mingw (for cross-compiling c)
- python 3.10+

## build instructions
run the makefile to compile all native binaries and stage the python scripts.
\`\`\`bash
make all
\`\`\`
artifacts will be dropped in the \`/bin\` directory.

## running the simulation
1. start the isolated victim network:
\`\`\`bash
make run_lab
\`\`\`
2. execute the injector on \`patient_zero\` to observe p2p mesh formation and golang subnet saturation.
3. monitor network traffic within the \`sim_net\` docker bridge to analyze the dga fallback and lateral movement signatures.

## architecture notes
- **evasions (rust):** demonstrates memory unhooking techniques.
- **propagation (go):** high-concurrency port scanning and exploitation simulation.
- **core (python):** handles the p2p decentralized tasking logic.
